订阅规则

给你的机场订阅自动加上分流规则：国内直连、国外走代理、屏蔽广告。节点不变。

  1. 到机场后台复制 Clash 格式的订阅地址
  2. 粘贴到下方，点 生成地址
  3. 复制新地址，在 Clash 客户端里 导入订阅
  4. 以后照常更新订阅即可，节点和规则都会自动同步

需为 Clash（YAML）格式，JMS 订阅地址末尾带 format=clash。

常见问题

支持哪些客户端？

需要 mihomo（Clash Meta）内核：Windows / macOS 用 Clash Verge Rev，Android 用 FlClash 或 Clash Meta for Android，iOS 用 Stash。原版 Clash 已停更，不支持 VLESS 等新协议。

会改动我的节点吗？

不会。节点原样来自你的订阅，本服务只添加分组和分流规则。流量信息也会照常显示。

新地址泄露了怎么办？

输入原订阅地址，点「重置地址」。旧地址立即失效，把新地址重新导入客户端即可。

重复点生成会怎样？

同一个原订阅永远得到同一个地址，不会失效，可以放心再次获取。

「从本服务器下载」是什么？

分流规则由客户端每天自动更新，默认从 jsDelivr 下载。jsDelivr 在部分地区或网络下访问不稳定，可能导致规则下载失败、分流不生效。开启后改从本服务器下载，服务器会定期缓存最新规则。如果默认方式正常，无需开启。
