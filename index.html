Routing rules for China and overseas

A subscription usually only includes servers, so every connection goes through the proxy. This adds rules for Clash, mihomo, and Stash: in China, Google and YouTube use your proxy while local sites stay direct; overseas, send WeChat, Alipay, and DingTalk through a China-exit node so they do not see a foreign IP. Common ads are blocked. Your servers are not changed.

  • International / China split
  • China-exit for domestic apps
  • Ads blocked
  • Servers unchanged
  1. Copy one or more Clash YAML subscription URLs
  2. Paste each URL; keep AUTO on airport nodes, uncheck it on a China-exit / residential source
  3. Import the new link in your client
  4. Update as usual. Nodes merge across sources; rules stay in sync

Up to 8 sources. AUTO = url-test (lowest latency). Uncheck it for a China-exit node so it never wins on latency but stays available under China.

Questions

Which clients work?

You need a mihomo (Clash Meta) core: Clash Verge Rev on Windows and macOS, FlClash or Clash Meta for Android, and Stash on iOS. Original Clash is unmaintained and does not support protocols such as VLESS.

Will my servers change?

No. Servers come from your subscription unchanged. This only adds groups and routing rules. Traffic stats still show up.

What if the new link leaks?

Enter the original subscription URL and click Reset link. The old link stops working immediately. Import the new one in your client.

What if I click Create link again?

The same original subscription always gets the same link. Pasting a link this site already generated will be rejected.

What does “download rules from this server” mean?

Clients refresh rule lists about once a day, from jsDelivr by default. If that CDN is hard to reach, rules fail to update. Turn the switch on to fetch them from this server instead. Leave it off when the default works.

Can I merge multiple subscriptions?

Yes. Add multiple sources. Nodes are merged (duplicate names get a #2 suffix). Uncheck AUTO to exclude that source from url-test. Exhausted sources are dropped.

What does AUTO do?

AUTO puts that source into the url-test group, which always picks the lowest-latency node. Uncheck it for a residential or China-exit source: those IPs look like a real household, but they are rarely the fastest, so url-test would never keep them. They still appear in Proxy and China for manual use.

I live overseas. How do I use this?

Import as usual, then in the client set the China group to your China-exit node. WeChat, Alipay, DingTalk, and other CN sites will use that IP. Leave China on DIRECT if you live in China.
